一个小站，
三篇能复现的记录

这里是 hhh-ai-homework 的博客部分。文章写的都是这个仓库里真实发生过的事：哪一页、哪个脚本、哪个数字对不上。

谁写的
{{AUTHOR}}。GitHub 同名，仓库里能看到每一个页面的构建脚本与验收记录。
这个站是什么
三篇文章的静态站点。文章本身是 Markdown，构建时渲染成 HTML；没有数据库，没有评论，没有统计脚本。
怎么构建
一个 Python 脚本读 posts/posts.json 与 posts/<slug>.md，渲染出列表页、文章页、RSS 和这一页。产物直接提交，克隆下来就能打开。
技术选择
手写 CSS 加一层设计令牌（近黑底、单一强调色、一种圆角、一套缓动）。没有框架，没有 CDN 字体，没有外部请求。
关掉 JavaScript 之后
全文可读。脚本只做三件事：顶部阅读进度、区块入场、代码块复制按钮。
数字从哪来
文章里出现的训练数字都在 assignment-01-xor-mlp/data/metrics.json（原版）与 assignment-01-xor-mlp/v2/data/metrics.json（升级版重建，逐位一致）里，由 v2/code/verify.py 的 23 项检查覆盖。
来源
仓库：github.com/hhfree1/hhh-ai-homework。作业展示页与 XOR 回放台在同一仓库的另外两个目录。

三篇在讲什么

  • 页面里的数字，一个都不许手写：301 帧、9632 个数，全部由脚本注入；代价是模板不能直接预览，收益是改样式时不会碰坏数字。
  • 2-2-1 网络学 XOR：九个参数逐帧记录，末轮隐藏层把四个点搬到两个簇；20 次随机初值里 9 次学会，失败的 11 次停在 0.69。
  • 无头截图的四个坑：命名管道、后台任务被清扫、离屏图片不栅格化、入场动画没触发。四个坑的表现都是「页面看起来坏了」。
