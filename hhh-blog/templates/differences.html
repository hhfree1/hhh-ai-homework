这个站故意
少做的六件事

同类的个人作业站习惯给每个作业配一张卡片、一组评分、一排标签。这个站反过来：去掉能去掉的，只留下能被验证的部分。

下面每一条都是「本站怎么做 / 为什么」。参考站指的是这类个人作业汇总页的常见形态，不是对某一个具体站点的评价。

  1. 没有作业卡片，只有一个文章列表。卡片要封面图、标签、状态徽章，三样都需要维护，而这里一共三篇文章。列表只给日期、标题、一句摘要和字数，读者一眼扫完。
  2. 没有评分、星级、进度条。作业的「分数」不在作者的掌控范围内，把它画在页面等于替评审发言。这里只写做完了什么、怎么验证。
  3. 不显示「阅读时长」，显示字数和日期。阅读时长是按每分钟几百字估出来的，估法不公开就是编造。字数由构建脚本数出来，日期来自文件元数据。
  4. 保留了 feed.xml。三篇文章也值得一个 RSS 入口——全文摘要，不带统计参数，地址写死在一个常量里，部署时改一行。
  5. 不做标签页、不做站内搜索。三篇的量级，目录就是索引。等文章多到列表要滚两屏再加，那时才知道该按什么维度分。
  6. 零外部请求。没有 CDN 字体、没有图标库、没有统计脚本、没有评论插件。字体用系统栈，图形用 CSS 与内联 SVG，页面在断网状态下与联网时一模一样。

另一条不属于「少做」但同样刻意的取舍：文章全部在构建期生成 HTML。所以关掉 JavaScript 之后，标题、正文、脚注、上下篇链接都在原位，脚本只增加一点滚动反馈。
