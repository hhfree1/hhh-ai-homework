## 作业 01 摘要

- **动态演示**：把 300 轮训练的**每一轮**参数记录下来，在页面上回放——左侧判定区域逐步长出两块对角区域，右侧四个样本被搬进隐藏空间，`00` 与 `11` 重合于原点
- **实测结果**：损失 `0.5620 → 0.0279`，四个样本预测 `0,1,1,0`，概率 `0.03 / 0.97 / 0.97 / 0.03`
- **对照实验**：初值换成随机数重复 20 次，9 次全对——说明「结构有能力」不等于「每次都能练出来」
- **环境**：Python 3.13.14 + PyTorch 2.15.0+cpu，CPU 训练约 7 秒
